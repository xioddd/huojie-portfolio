# 《活结》个人独立民俗恐怖解谜游戏

《活结》是一款以粤西虚构古镇“绛水镇”为背景的网页恐怖解谜游戏。玩家以远程协助者的身份，进入“过绳节民俗馆”网页、即时通讯、调查资料与工业档案，在碎片化线索中逐步拆开一段被官方叙事掩埋的旧事。

作品围绕“过绳节”这一虚构民俗展开：一根红绳表面象征祝福、牵系与守护，背后却不断把“留下”包装成正确选择。玩家需要通过网页搜索、照片背面、旧档案、聊天记录、工业遗迹和现场照片，还原梁绫七年前的死亡真相，并理解何家姐弟正在面对的相似困境。

## 核心体验

玩家不是被动观看剧情，而是在“像真的在调查”的界面中主动寻找信息。游戏将民俗馆网页、新闻检索、即时通讯、文件夹、工业档案和现场照片整合为一个可探索的桌面系统，让玩家通过阅读、比对、排序与验证逐步接近真相。

作品的恐怖感不只来自红绳、水鬼、旧宗祠和禁忌传闻，也来自旧礼节对个体选择的压迫。随着调查推进，玩家会发现所谓“祝福”的仪式，曾经如何让亲情、牺牲和服从纠缠在一起。

## 章节概览

### 第一章：背景调查与小葵姐弟

玩家从民俗馆网页、新闻关键词和人物资料开始调查，初步发现“过绳节”的官方叙事存在缺口。随后，小葵的毕业照、录取通知书和弟弟的画补上更柔软的真相：小葵想离开镇子读书，弟弟也希望姐姐拥有自己的生活，他们并不是彼此的拖累，而是在旧礼节压力下互相保护。

### 第二章：姐姐的苦心

调查推进到梁绫与梁穗的姐妹关系。作品不直接替玩家解释姐姐的动机，而是让玩家从聊天语气、时间细节、箱子里的车票、录取通知书和姐妹合影中，逐步读出梁绫曾经如何保护妹妹。她的选择不是软弱的服从，而是在家庭压力、旧礼节与现实限制之间，为妹妹争取一条更自由的路。

### 第三章：工业遗迹与死亡真相

玩家进入染坊与工业遗迹调查，通过旧厂房登记、设备检查记录、平面图和现场照片，还原梁绫死亡前最后十五分钟。水鬼传闻逐渐被拆解成可观察、可比对、可验证的证据链：她被困在三号染池附近，出口被堵，水位上升，现场留下的时间、位置和物件彼此印证。

### 第四章：回忆与救援

七年前梁家姐妹因为旧礼节而阴阳两隔，如今相似的悲剧又在何家姐弟身上重演。梁穗在他们身上看见曾经的姐姐与自己，于是试图完成姐姐没能完成的愿望。终章中，红绳的意义被重新翻转：它不再只是束缚人的仪式，而成为村民合力救援的工具。

### 尾声：余波与系列彩蛋

尾声通过民生新闻、救助制度更新、人物去向和与绫娘的对话，交代绛水镇在事件后的改变。最后的对话既是对本作主题的总结，也暗含下一个系列游戏的引入。

## 作品表达

《活结》想讨论的不是“传统是否应该被保留”这样简单的判断，而是：当一种礼节开始要求个体牺牲选择、沉默痛苦、服从命运时，它是否还值得被原样延续。

真正值得留下的不是让人被迫服从的仪式形式，而是人们愿意在关键时刻伸手帮助彼此的情感与责任。游戏以民俗恐怖为外壳，核心仍然落在亲情、选择、救援与共同体的温度上。

## 制作说明

本作由个人独立完成，从叙事设计、文案撰写、视觉素材规划、图片 Prompt、音乐 Prompt 到前端实现均由本人主导完成。

制作过程中使用了 ChatGPT、Codex、Cursor、即梦 AI 等工具辅助进行剧情文案、图片生成、代码实现与作品集整理。重点并不是简单使用 AI 生成内容，而是通过持续的审美判断、Prompt 迭代和交互调试，将分散素材整合成一个完整、可游玩、可展示的作品。
