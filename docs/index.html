Game Overview

一根红绳绑住旧礼节，也牵出人与人之间的救援。

《活结》围绕虚构古镇绛水镇的“过绳节”展开。玩家跟随好友梁穗调查姐姐梁绫七年前的死亡真相，从民俗馆网页、新闻检索、聊天记录、老照片、工业档案和现场资料中逐步发现：所谓“祝福”的仪式，曾经如何把个体选择改写为必须服从的命运。

作品的核心并不是单纯制造惊吓，而是让玩家在解谜过程中看见被旧礼节遮住的人。小葵想读书，弟弟也希望姐姐拥有自己的生活；梁绫曾经试图保护妹妹，梁穗则在何家姐弟身上看见过去的自己。恐怖来自绳结的压迫，温情来自人们终于愿意一起把结解开。

Chapter Design

章节梗概与设计重点

01 第一章：背景调查与小葵姐弟

从官方民俗叙事进入，再把调查落到“一个人是否拥有选择”。

玩家先通过民俗馆网页、新闻关键词和人物资料认识过绳节：它表面上是祈福、牵系与守护，背后却不断把“留下”包装成正确选择。随后，小葵的毕业照、录取通知书和校门口照片建立她想离开镇子读书的现实处境；弟弟的画则补上更柔软的真相，他并不想拖住姐姐，而是希望姐姐背着书包走向自己的生活。

这一章的个人能力展示在于体验引导、图像伏笔和信息节奏：先让玩家理解操作规则，再通过照片背面、红绳、校车与弟弟视线，把“民俗祝福”转译成逐渐成形的压迫感。

02 第二章：姐姐的苦心

让玩家在细节中读懂爱，而不是直接听角色解释爱。

第二章把调查推进到梁绫与梁穗的姐妹关系。作品不直接替玩家说明姐姐的动机，而是让玩家从聊天语气、时间细节、照片背面和房间物件中，逐步读出梁绫曾经如何保护妹妹。她的选择不是软弱的服从，而是在旧礼节、家庭压力与现实限制之间，为妹妹争取一条更自由的路。

这一章强调人物动机与作品内涵的结合：民俗恐怖不只来自红绳和禁忌，也来自“以爱之名要求牺牲”的结构。玩家越接近姐姐的真实想法，越能理解梁穗为什么必须回到绛水镇，把当年没能说出口的事重新说清。

03 第三章：工业遗迹与死亡真相

把传闻拆成可观察、可比对、可验证的证据链。

第三章转入染坊与工业遗迹调查。玩家需要阅读旧厂房登记、设备检查记录、平面图和现场照片，逐步还原梁绫死亡前最后十五分钟：她被困在三号染池附近，出口被堵，水位上升，现场留下的时间、位置与物件互相印证。

这一部分展示了证据链设计能力：平面图、老照片、工业档案与聊天记录彼此交叉，让玩家不是被动听到真相，而是通过观察、排序、比对和验证，把“水鬼传闻”还原成一场被掩盖的人祸。

03 延展：亮度谜题与逐步逼近的恐怖

用“看清照片”的动作，让玩家亲手靠近被压住的真相。

玩家需要调整照片亮度，让原本被黑暗吞掉的现场细节一点点浮现。随着画面变亮，姐姐在水面下的轮廓、水鬼逐渐爬出的视觉压迫、满屏红字诉说的愿望与请求，会把调查从理性取证推向强烈的情绪冲击。

这一页突出恐怖节奏与交互叙事：谜题不是单独存在的机关，而是与恐惧、证据和人物愿望同时发生。玩家每推进一步，都更清楚姐姐不是传闻里的“鬼”，而是一个曾经求救、也曾经想活下去的人。

04 第四章：回忆与救援

七年前的悲剧在眼前重演，玩家要推动故事走向另一种结局。

第四章让梁穗看见何家姐弟身上的相似命运：七年前，梁家姐妹因为旧礼节而阴阳两隔；如今，小葵与弟弟也被同样的逻辑推向牺牲。弟弟支持姐姐求学，即使患有癫痫，也想成为能够独立生活的人；小葵关心的不只是自己能不能离开，也希望镇上建立更完善的救助与帮扶规则。

梁穗在他们身上看见曾经的姐姐与自己。她想完成梁绫没有完成的愿望，救下这对姐弟，也让绛水镇从“必须服从旧礼节”的循环中被拉出来。

水彩风格的回忆画面弱化现实边界，让何素琴的回忆变得朦胧、柔软，也更像一次迟来的理解：她终于意识到，旧礼节伤害的从来不是某一个人，而是一代又一代没有被允许选择的人。

04 延展：合绳救援

真正值得留下的不是束缚人的仪式，而是人们愿意互相帮助的情感。

终章救援把“红绳”的意义重新翻转。前半段里，绳代表束缚、规训和被迫留下；到了合绳救援，村民们把各自手中的绳交出来，不再用它困住谁，而是用它救人。这个设计让作品从民俗恐怖走向人文表达：改变不是来自某个角色单独成为英雄，而是来自更多普通人愿意伸手。

这一章展示群像叙事、情绪高潮与主题回收能力。玩家完成的不只是一个谜题，而是见证一套旧叙事被新的行动替代。

05 尾声：余波与系列彩蛋

结已经解开，但真正的改变才刚刚开始。

尾声通过民生新闻、救助制度更新、人物去向与和绫娘的对话，交代绛水镇在事件后的改变。最后的对话既是对本作主题的总结，也暗含下一个系列游戏的引入：梁绫留下的不只是一次真相揭露，更像一条通向更大世界的线索。

在这一刻，民俗恐怖从“未知的禁忌”转变为“被重新理解的记忆”。玩家离开页面时，带走的不是单纯的惊吓，而是关于选择、亲情、救援与共同体责任的余味。

“这次轮到你解结。”这句尾声回响既完成本作闭环，也把玩家引向下一段关于旧物、记忆与地方传说的调查。

Production Ability

从文案、审美到 Vibe Coding：独立形成完整作品

叙事与文案

独立完成世界观、章节结构、人物关系、聊天文本、档案信息与线索提示，把“旧礼节的桎梏”转化为可互动、可推理、可共情的游戏体验。

视觉审美与图片 Prompt

使用即梦 AI、ChatGPT 图像生成等工具制作剧情图、旧照片、档案图与恐怖场景，并通过 Prompt 迭代控制画面情绪、年代质感和叙事信息密度。

音乐与声音设计

撰写音乐 Prompt 与音效逻辑，围绕民俗馆、调查、恐怖高潮、回忆与尾声分别建立声音氛围，让音频服务章节节奏而不是单纯铺底。

代码落地与 AI 协作

结合 Cursor、Codex 与 ChatGPT 进行前端实现、问题排查、交互迭代和作品集整理，完成可游玩的网页游戏、PPT 作品集与 HTML 展示页。

For Interview
